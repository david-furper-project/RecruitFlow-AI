# Contexto del Proyecto: Plataforma de Reclutamiento Inteligente (PRI)

## Objetivo
El objetivo del sistema es resolver la fricción operativa sistémica en el ecosistema de reclutamiento. Esto se logra mediante:
- La eliminación de la captura manual y duplicada de datos para el candidato.
- La automatización del filtrado y notificación para el reclutador.

*Nota: No se desarrollará el dashboard de KPIs de gerencia en esta fase (MVP).*

## Flujos de Usuario Principales

### 1. Flujo del Candidato
- El candidato postula a las ofertas de trabajo.
- Sube su CV (PDF) o se autentica/extrae datos vía LinkedIn para evitar el ingreso manual repetitivo.
- El sistema extrae y procesa su información de forma automática.

### 2. Flujo del Reclutador
- El reclutador evalúa a los candidatos postulados.
- El sistema realiza un filtrado inteligente, comparando el perfil del candidato con los requisitos del puesto (Scoring de similitud).
- Se automatizan las notificaciones de estado hacia los candidatos, manteniéndolos informados sobre su proceso.
